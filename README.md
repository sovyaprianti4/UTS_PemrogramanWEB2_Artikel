# Implementasi WebSocket sebagai Solusi Komunikasi Real-Time

## Deskripsi

Proyek ini dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web 2. Proyek membahas implementasi WebSocket sebagai teknologi komunikasi real-time pada aplikasi web berdasarkan studi literatur dari beberapa jurnal ilmiah.

WebSocket memungkinkan komunikasi dua arah (full-duplex) antara client dan server melalui satu koneksi yang tetap terbuka sehingga mampu meningkatkan efisiensi komunikasi data dibandingkan metode HTTP tradisional yang menggunakan mekanisme request-response.

## Tujuan

- Memahami konsep dasar WebSocket.
- Menganalisis implementasi WebSocket pada aplikasi real-time.
- Membandingkan WebSocket dengan metode polling.
- Mengetahui kelebihan WebSocket dalam efisiensi bandwidth dan kecepatan komunikasi data.

## Teknologi yang Dibahas

- WebSocket
- HTTP
- Polling
- Komunikasi Real-Time
- Aplikasi Web
- Internet of Things (IoT)

## Hasil Pembahasan

Berdasarkan hasil analisis beberapa jurnal, WebSocket memiliki beberapa keunggulan, antara lain:

- Mendukung komunikasi dua arah secara real-time.
- Mengurangi penggunaan bandwidth dibandingkan metode polling.
- Memiliki latensi yang rendah.
- Cocok digunakan pada aplikasi chat, IoT, game online, dan sistem notifikasi.
- Mampu menangani komunikasi data secara efisien pada aplikasi berskala besar.
